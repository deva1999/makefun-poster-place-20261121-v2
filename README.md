KORVANE — a travel poster for a place that isn't there. One impossible act, drawn literally: a giant iceberg has risen out of the sea into the dusk sky, carrying a lighthouse village on its flat top — where the icebergs learn to fly. A pure-Node, dependency-free, deterministic program that paints the poster pixel by pixel (layered dusk gradient, aurora, sun, faceted berg, sea, gulls, and hand-drawn geometric type) and writes it to `/output/entry.png`.

## Run it

```sh
node main.ts
```

The program writes a 1024×1024 PNG to `/output/entry.png` (override with the `OUTPUT_PATH` environment variable). It needs no network and no dependencies, and two runs produce byte-identical output.
